# Локальное тестирование Lacan

Это исследовательская версия 0.1.0-local. Для установки нужен Android 13+ (API 33) и arm64. Основное целевое устройство — Galaxy A56. Сборка не является публикацией в Google Play.

## Установка на A56

1. Передать `artifacts/lacan-local-alpha.apk` на телефон и открыть. Android предложит разрешить установку этому источнику. Либо установить с компьютера: `adb install -r artifacts/lacan-local-alpha.apk` после подключения USB и подтверждения отладки на телефоне.
2. Открыть Lacan → Настройка. Разрешить микрофон, уведомления и отображение поверх других приложений. В системных специальных возможностях включить Lacan.
3. Если Android блокирует специальную возможность для установленного из файла APK: открыть сведения о приложении Lacan → меню ⋮ → «Разрешить ограниченные настройки», затем вернуться к специальным возможностям. Названия пунктов зависят от One UI; не отключать другие защиты телефона.
4. В «Модели» скачать модель и выбрать её. Whisper tiny Q5 ≈33 МБ — быстрый старт; base Q5 ≈60 МБ — сравнение качества. GigaAM v3 e2e CTC int8 ≈320 МБ — русский с пунктуацией. Требование к RAM значительно выше размера файла.
5. Для смешанной русской/английской речи начать с Whisper и «Русский» либо «Авто». GigaAM ориентирована на русский; английские вставки ещё требуют оценки.
6. Открыть текстовое поле в другом приложении. При видимой клавиатуре появляется кнопка Lacan. Перетащить её на удобное место. Первое нажатие начинает запись, повторное завершает. Короткое видимое окно запуска необходимо для разрешённого старта микрофона на новых Android.
7. Во время записи можно менять приложения. Итог вставляется в текущее активное подходящее поле. Если вставку невозможно выполнить или подтвердить, появится ручное копирование. При неопределённой вставке сначала проверить поле: текст мог уже появиться.

Без специальной возможности доступны запись внутри Lacan и копирование результата из приложения. Разрешение поверх окон нужно для плавающей панели. В локальной альфе запись требует разрешённых уведомлений, чтобы Стоп и Отмена оставались доступны при переключении приложений; отключение уведомлений во время записи останавливает её.

## Приватность и данные

После загрузки модели проверить работу в авиарежиме. Аудио и текст не отправляются на сервер. История содержит последние100 непустых результатов; «Отмена» не сохраняет диктовку. Аудио находится только во временном приватном PCM-файле, удаляется по окончании/отмене и при запуске после сбоя. Ранее распознанные фрагменты восстанавливаются из локального черновика; нераспознанный хвост после убийства процесса не восстанавливается. Backup и перенос данных отключены.

При блокировке или выключении экрана запись заканчивается; автоматическая вставка этой сессии запрещена. После разблокировки запись сама не возобновляется.

## Сборка из исходников

Нужны JDK21, Android SDK (platform36, build-tools36.0.0), NDK27.2.12479018, CMake3.22.1. Пусть `JAVA_HOME` указывает на JDK21, а `ANDROID_HOME` или `sdk.dir` в локальном `local.properties` — на SDK. Android Studio может включать JDK25: он не подходит для закреплённого Gradle8.13; использовать отдельный JDK21.

```sh
./tools/prepare-asr.sh
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

`tools/build-local.sh` выполняет эти шаги и копирует APK в `artifacts/`. На текущей машине JDK21 и Gradle-кэш находятся в игнорируемой `.tools/`. Подпись debug предназначена только для тестирования, её ключ не публикуется. Переустановка APK, подписанного другим debug-ключом, может потребовать удаления предыдущей установки и её данных.

Whisper.cpp и Sherpa загружаются из закреплённых открытых выпусков; скрипт проверяет SHA-256. Модели не входят в APK и репозиторий. Их версии, размеры, хеши и HTTPS-источники зафиксированы в `ModelCatalog.kt`. Лицензии зависимостей находятся в `THIRD_PARTY_NOTICES.md` и assets APK.

## Проверка на устройстве

- Обычное поле, многострочное поле, WebView, поле браузера: вставка в курсор, замена выделения, сохранение остального текста.
- Поля пароля: кнопка не предлагается и автоматическая вставка не выполняется.
- Перейти в другое приложение и вернуться; выбрать другое поле перед окончанием; завершить без поля → ручное копирование.
- Отменить запись и обработку, затем сразу попробовать новую сессию: не должно быть старого текста, второй истории или параллельных микрофонов.
- Закрыть клавиатуру в ожидании → кнопка скрыта; во время записи → доступна панель/уведомление.
- Выключить экран/заблокировать: микрофон останавливается, текст только в истории.
- Тишина, тихая речь, шум, длинная фраза без пауз, намеренное «да, да», речь10минут; проверить границы и хвост.
- Русский, английский, смешанные технические термины. Сравнивать одинаковую речь на Whisper/GigaAM.
- Проверить нагрев, расход памяти, задержку после стопа и сохранение тёплой модели на A56.

## Инструментальные тесты и тестовые файлы

Тесты `:app:connectedDebugAndroidTest` читают модели и аудио из приватного каталога установленного приложения: `/data/user/0/org.lacan/files/test-fixtures`. Тестовых файлов в APK и Git нет. Для ASR-тестов подготовьте на компьютере каталог со следующей структурой:

```text
test-fixtures/
├── test-audio/
│   ├── jfk.wav
│   └── gigaam-example.wav
└── test-models/
    ├── whisper-tiny/
    │   └── ggml-tiny-q5_1.bin
    └── gigaam-v3/
        ├── gigaam_v3_e2e_ctc_int8.onnx
        └── gigaam_v3_e2e_ctc_tokens.txt
```

WAV-файлы должны быть публичными тестовыми записями в формате mono PCM16, 16 кГц. Модельные файлы должны соответствовать именам и SHA-256 в `ModelCatalog.kt`; тест при импорте проверяет хеши через `ModelRepository`. Не подставляйте в эти фикстуры личные записи: smoke-тест сохраняет распознанный текст и время обработки рядом с аудио.

Сначала выберите устройство по выводу `adb devices -l`, затем задайте его serial в `ANDROID_SERIAL` и корневой каталог фикстур в `FIXTURE_ROOT`. Подставьте свои значения вместо примеров:

```sh
export ANDROID_SERIAL="YOUR_DEVICE_SERIAL"
export FIXTURE_ROOT="/path/to/test-fixtures"
adb -s "$ANDROID_SERIAL" shell run-as org.lacan mkdir -p files/test-fixtures
tar -C "$FIXTURE_ROOT" -cf - . | adb -s "$ANDROID_SERIAL" exec-in run-as org.lacan tar -xf - -C files/test-fixtures
./gradlew :fixture:installDebug
```

Gradle выберет устройство по `ANDROID_SERIAL`. Запустите наборы по классам, чтобы повторить проверенный набор из 10 тестов (5 истории, 2 жизненного цикла записи, 1 внешнего редактора и защиты поля пароля, 2 ASR):

```sh
./gradlew -Pandroid.testInstrumentationRunnerArguments.class=org.lacan.history.HistoryStoreTest :app:connectedDebugAndroidTest
./gradlew -Pandroid.testInstrumentationRunnerArguments.class=org.lacan.runtime.RecordingLifecycleTest :app:connectedDebugAndroidTest
./gradlew -Pandroid.testInstrumentationRunnerArguments.class=org.lacan.access.DeliveryIntegrationTest :app:connectedDebugAndroidTest
./gradlew -Pandroid.testInstrumentationRunnerArguments.class=org.lacan.asr.AsrSmokeTest :app:connectedDebugAndroidTest
```

Плавающую кнопку и отмену записи проверяет отдельный UI-тест:

```sh
./gradlew -Pandroid.testInstrumentationRunnerArguments.class=org.lacan.access.OverlayIntegrationTest :app:connectedDebugAndroidTest
```

ASR-тесты сохраняют публичный распознанный текст и время инференса в `whisper-smoke-result.txt` и `gigaam-smoke-result.txt`. Их можно прочитать так:

```sh
adb -s "$ANDROID_SERIAL" shell run-as org.lacan cat files/test-fixtures/whisper-smoke-result.txt
adb -s "$ANDROID_SERIAL" shell run-as org.lacan cat files/test-fixtures/gigaam-smoke-result.txt
```

## Ограничения локальной альфы

- CPU, только arm64; нет обещания приемлемой скорости всех моделей на любом телефоне.
- Временный energy VAD с порогом громкости вместо Silero: тихая речь/шум требуют особенно внимательных тестов. Принудительные границы20с с перекрытием750мс, preview до8с не чаще2с при свободной очереди.
- Автоопределение языка Whisper фиксируется после первого распознанного окна сессии; короткое начало может быть ошибочно классифицировано. При необходимости выбрать язык явно.
- Не все редакторы предоставляют пригодный InputConnection. Длинные вставки >4096символов могут успешно вставиться, но остаться «не подтверждёнными»; повторной автопопытки нет.
- Положение панели ограничивается доступной областью экрана и ближайшим краем. Детальная настройка формы/цвета/иконки отложена.
- Эмулятор не доказывает поведение One UI, нагрев, качество микрофона или скорость A56. Для минимальной версии Android API 33 проверку пока не проводили.

## Выполненные проверки

Зафиксированные результаты локальной проверки:

- JVM: все 19 тестов прошли — 9 в `core`, 6 проверки целостности моделей и 4 проверки политики целевого поля.
- Android lint: 0 ошибок, 28 предупреждений.
- Debug APK: около 59 МБ, arm64; подпись v2; нативные библиотеки собраны для страниц памяти 16 КБ.
- Эмулятор Android API 37 с отключёнными Wi-Fi и мобильными данными: итоговый совместный прогон всех 11 инструментальных тестов прошёл, включая реальное нажатие плавающей кнопки, запуск записи и отмену.
- Samsung Galaxy A56 SM-A566E, Android 17 / API 37, около 8 ГБ RAM: прошли оба ASR smoke-теста. GigaAM v3 int8 обработала публичный русский клип длиной 11,29 с за 1021 мс и вывела пунктуацию. Whisper tiny Q5 обработала 11-секундный английский клип за 1594 мс. Это короткие тестовые клипы, не длительный замер производительности.

Остаются ручные проверки: десятиминутная запись, нагрев, качество смешанной речи и совместимость с редакторами. API 33 пока не проверяли. Эти результаты относятся к указанным устройствам и коротким фикстурам; они не подтверждают работу на всех телефонах или качество длинной диктовки.

На A56 также прошли два UI-теста: запуск и отмена записи плавающей кнопкой, вставка в курсор чужого приложения с сохранением текста и отказ от вставки в пароль. Разрешения пользователь включил вручную. Samsung после перезапуска процесса инструментальным тестом оставляет службу доступности отключённой; режим тестов `-e pregranted true` переподключает только уже разрешённую службу. Это подготовка тестового стенда, а не действие обычного приложения.

```sh
adb -s "$ANDROID_SERIAL" shell am instrument -w -r -e pregranted true -e class org.lacan.access.OverlayIntegrationTest,org.lacan.access.DeliveryIntegrationTest org.lacan.test/androidx.test.runner.AndroidJUnitRunner
```
