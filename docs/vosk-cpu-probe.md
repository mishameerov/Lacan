# Vosk CPU: первая интеграция

21 октября 2026 года, Lacan 0.1.4-prototype (versionCode 5).

Добавлен Vosk Android 0.3.75 с компактной русской моделью `vosk-model-small-ru-0.22`. Модель скачивается отдельно, выполняется локально на CPU. Это эксперимент для сравнения: пунктуация и смешанная русско-английская речь этой моделью не обеспечиваются. Переключатель языка не меняет язык весов Vosk; ограничение указано в карточке модели.

## Артефакт и установка

- Официальный источник: https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
- Загрузка из каталога: закреплённый mirror https://huggingface.co/rhasspy/vosk-models/resolve/e7ac2109d134b5f2404ba95389b2fb51916d4cab/ru/vosk-model-small-ru-0.22.zip
- SHA-256 официального архива совпал с mirror: `961d5ff98a17f4aa6de69864d0aa71fa5bac682301d2b5d17a3f24c5c99a46d4`.
- Архив 46,236,750 байт; распакованные файлы 91,289,240 байт.
- Лицензия модели и Vosk — Apache-2.0; JNA 5.18.1 используется по Apache-2.0.

Перед созданием движка архив проверяется по размеру/SHA-256 и заново распаковывается в staging. Пути, дубликаты, объём и обязательные файлы проверяются; публикация каталога атомарна. Уже загруженный движок переиспользуется между диктовками. Холодная загрузка платит дополнительным чтением/распаковкой за восстановление доверенных байтов из архива.

Recognizer создаётся для каждого существующего окна Lacan; входные float PCM16k преобразуются обратно в PCM16 без переполнения. Собираются завершённые endpoint-фразы и final tail. Отмена проверяется между вызовами по 100 мс аудио; закрытие Model сериализовано с распознаванием. Это интеграция с текущим оконным pipeline, не использование всех возможностей нативного streaming Vosk.

## Проверки

- 35 JVM-тестов: core 11, app 24; ошибок нет. Включены проверки PCM, zip-slip, дубликатов, неполного архива, ограничений объёма и замены изменённых распакованных файлов.
- Сборка app + instrumentation APK успешна; lint: 0 ошибок, 30 предупреждений.
- APK zipalign для 16 KB пройден; `libvosk.so` и `libjnidispatch.so` имеют LOAD alignment 0x4000.
- На Galaxy A56 / Android 17 по Wi-Fi ADB установлен APK 0.1.4. `VoskSmokeTest` прошёл: русский публичный фрагмент, тишина, повторное использование после cancel. Микрофон не использовался; выбранная пользователем модель не менялась.
- Первый decode шестисекундного фрагмента `gigaam-example.wav`: **7,715 мс**. Это единичный smoke-test при текущем состоянии телефона, не контролируемый benchmark и не оценка WER. Результат содержит ошибки и не имеет пунктуации. Время загрузки/распаковки не включено в decode-метрику.
- Минимальный запуск MainActivity после теста успешен.

Этот результат подтверждает совместимость native CPU-пути. Он не доказывает превосходство над GigaAM/Parakeet и не проверяет отмену посреди активного native decode.
