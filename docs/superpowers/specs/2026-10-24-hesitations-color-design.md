# Фильтр заминок и цвет кнопки

Пользователь согласовал лёгкую очистку итогового текста и выбор цвета. Фильтр включён по умолчанию; состояние сохраняется и фиксируется при начале диктовки. Он обрабатывает только склеенный итог, одинаково для вставки, истории и ручного копирования. Черновой текст и алгоритм склейки не меняются. Запись только из заминок не должна оставлять восстанавливаемый черновик.

Вместо повторного распознавания или дополнительной модели выбран локальный текстовый фильтр: он не требует вычислений ASR и не перефразирует речь. Удаляются явные повторные звуки; одиночные слова, аббревиатуры и единицы измерения сохраняются. Междометия остаются неоднозначными, поэтому предусмотрен выключатель.

Оранжевый — новый цвет по умолчанию. Палитра: оранжевый, жёлтый, зелёный, бирюзовый, синий, фиолетовый. Красный остаётся только у отмены. Настройка сохраняется между запусками и применяется к основной кнопке во всех состояниях.

Проверка: JVM-примеры очистки и сохранения смыслового текста, существующие тесты приложения, lint, сборка debug/release. На A56 установлен debug: обновляем совместимым debug APK без удаления данных. Ручную проверку диктовки выполняет пользователь. Публичный релиз этой версии не запрошен.
