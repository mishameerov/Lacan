# Lacan

**Локальная голосовая диктовка для Android. Свободное программное обеспечение под GPLv3.**

Lacan разрабатывается как приложение с плавающей кнопкой, которое работает вместе с привычной клавиатурой. Распознавание речи выполняется на телефоне. Интернет нужен для скачивания выбранной модели; аудио и расшифровки не передаются на сервер.

## Статус

Проект находится на этапе согласования архитектуры. Исполняемого Android-приложения, APK и подтверждённых результатов производительности пока нет. Перечисленное ниже описывает планируемую первую версию.

## Первая версия

- Плавающая перемещаемая кнопка начала и окончания диктовки.
- Предварительное распознавание в бабле во время записи.
- Локальные Whisper и GigaAM с загрузкой проверенных моделей.
- Русский, английский и смешанная речь; возможности конкретных моделей проверяются отдельно.
- Расшифровка с пунктуацией, без отдельного редактирования или перефразирования.
- Диктовка до 10 минут с продолжением при переключении приложений.
- Остановка записи при блокировке экрана.
- Вставка результата в активное текстовое поле либо предложение скопировать текст вручную.
- Локальная история последних 100 расшифровок без аудиозаписей.
- Предлагаемый минимум Android 13; основное тестовое устройство — Samsung Galaxy A56.
