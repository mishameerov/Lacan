# Lacan

**Локальная голосовая диктовка для Android. Голос остаётся на устройстве.**

Lacan показывает плавающую кнопку у текстового поля, распознаёт речь на телефоне и вставляет итог в активный редактор. Пользователь сохраняет привычную клавиатуру. Проект — свободное программное обеспечение под GPLv3.

## Локальный прототип

В репозитории реализуется первая тестовая версия для **Android 13+ / arm64**. Целевое физическое устройство — Samsung Galaxy A56. Это исследовательская сборка: качество, скорость и совместимость редакторов проверяются на устройстве.

- Whisper base/small/medium/large-v3 ONNX int8 через sherpa-onnx для сравнения с прежним движком.
- Прежние Whisper Q5 через whisper.cpp сохранены как устаревший эксперимент для совместимости установленных моделей.
- Parakeet TDT 0.6B v3: ONNX CPU и отдельный экспериментальный LiteRT GPU, русский и английский с автоматическим определением языка.
- GigaAM v3 e2e CTC int8 и FP32 для русского с пунктуацией; GigaAM Multilingual600M int8 для русского и английского без пунктуации.
- Интерфейс Material3, динамические цвета Android и выбор системной, светлой или тёмной темы.
- Запись до10минут, отдельные круглые кнопки и капсула с предварительным текстом, звуковой диаграммой и таймером.
- Продолжение при смене приложения, остановка на выключении/блокировке экрана.
- Одна попытка вставки в текущий редактор; если она невозможна или не подтверждена — ручное копирование.
- История100 текстов, восстановление стабильного черновика после сбоя; без постоянной аудиоистории.
- Проверяемая загрузка моделей по HTTPS с закреплёнными SHA-256. Аналитики и облачного распознавания нет.

Размеры загрузок ONNX: Whisper small≈375МБ, medium≈946МБ, полный large-v3≈1,78ГБ; Parakeet≈670МБ. GigaAM v3int8≈320МБ, FP32≈886МБ, Multilingual600M≈592МБ. Прежние Whisper Q5 сохранены для совместимости. Модели скачиваются отдельно от APK; рабочая память больше размера файлов. [Каталог, источники и ограничения](docs/model-options.md).

## Сборка и запуск

Нужны JDK21 и Android SDK. Подробности установки APK, разрешений, сборки, ограничений и испытаний — в [инструкции локального тестирования](docs/local-testing.md).

```sh
./tools/prepare-asr.sh
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Готовый debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Скрипт `tools/build-local.sh` также сохраняет копию в `artifacts/lacan-0.1.11-prototype.apk`.

Для проверки вставки предусмотрено отдельное приложение `:fixture`; оно не входит в APK Lacan. Инструментальные тесты берут модели и публичные WAV-записи из приватного каталога приложения `files/test-fixtures`; каталог перед запуском передаётся на устройство вручную и не входит в APK или Git. Структура файлов и команды установки описаны в [инструкции локального тестирования](docs/local-testing.md). Не используйте личные записи в этих тестах.

В прототипе 0.1.1 добавлены Material3 со светлой/тёмной темой и [расширенный каталог моделей](docs/model-options.md), включая Whisper medium и многоязычную GigaAM600M. Это сборка для сравнения на устройстве; GitHub Release не публикуется.

В прототипе 0.1.3 добавлены Whisper Medium/Large-v3 ONNX и Parakeet, векторные элементы плавающей панели и затухание прокручиваемого текста. Крупные модели предназначены для ручного тестирования; аппаратное ускорение пока исследуется, текущие адаптеры работают на CPU.

В прототипе 0.1.4 добавлен [Vosk small RU на CPU](docs/vosk-cpu-probe.md), проверенный коротким тестом на A56. Это отдельный эксперимент без пунктуации и поддержки смешанного английского. [Проверка доступа к NPU A56](docs/a56-npu-access.md) обнаружила через NNAPI только reference CPU; GPU-путь Parakeet разрабатывается отдельно от основного APK.

В прототипе 0.1.5 [Parakeet GPU встроен в Lacan](docs/parakeet-gpu-integration.md): отдельная модель в каталоге, локальная загрузка и распознавание, без скрытого переключения на CPU. Совместимость пока проверена только на A56; другие телефоны требуют испытаний.

В прототипе 0.1.6 отключены повторные черновые прогоны Whisper: пузырь обновляется по завершённым фрагментам. [Замеры Medium ONNX на A56 и причины задержек](docs/whisper-performance.md). Добавлен отдельный экспериментальный [GigaAM FP32 GPU через MNN/OpenCL](docs/gigaam-gpu-probe.md) с проверяемым импортом локального файла модели. CPU-вариант сохранён.

В прототипе 0.1.7 основной каталог ограничен двумя моделями для текущего тестирования: **GigaAM v3 FP32 на CPU** и **NVIDIA Parakeet TDT v3 на CPU**. Прежний выбор экспериментальной модели переводится на соответствующий CPU-вариант (остальные — на GigaAM). Экспериментальные адаптеры и определения моделей сохранены в исходниках, скачанные файлы не удаляются. Внешние горизонтальные отступы плавающих кнопок теперь равны промежуткам между кнопками и пузырём: 10 dp.

В прототипе 0.1.8 улучшена склейка итоговых фрагментов: `е/ё` считаются одинаковыми, а одна изменённая/пропущенная/добавленная буква в длинном слове допускается при двух точно совпавших словах на стыке. Сравнение ограничено известным перекрытием и последними/первыми восемью словами; числа, короткие слова и расхождения в количестве слов не сопоставляются приблизительно. При неопределённости фрагмент сохраняется, поэтому некоторые дубли ещё возможны. Полного повторного распознавания и изменений анимации bubble нет.

В прототипе 0.1.9 добавлен мастер первоначальной настройки: модель, микрофон, уведомления, плавающая панель и специальные возможности. Если запуск невозможен, открываются настройки с объяснением. Раздел проверки диктовки удалён; язык остаётся в настройках. Кнопки и высота панели уменьшены до 38,5 dp при прежних промежутках 10 dp; подтверждение записи обозначено галочкой. Раскрытие панели и обратное сворачивание занимают по 300 мс. После подтверждённой вставки остаётся одна кнопка; при невозможности подтвердить вставку остаётся результат для копирования.

В прототипе 0.1.10 возвращена GigaAM Multilingual 600M int8 (русский и английский, также казахский, кыргызский и узбекский); скачивание использует прежние закреплённые файлы и SHA-256. В карточках оставлены название с производителем, языки и один размер. Иконка обновлена из `graphics/icon/icon-2.png`. Анимация панели перенесена с изменения размеров отдельных системных окон на отрисовку в неподвижном слое; на время 300-мс перехода используется имитация стекла без размытия, в неподвижном состоянии возвращается системное размытие.

В прототипе 0.1.11 запуск записи использует прозрачный нефокусируемый служебный экран без текста и затемнения. Ожидание модели показано кольцом и крестиком в панели до 10 секунд; закрытие панели не отменяет загрузку в память. Модель прогревается при запуске и появлении поля ввода, обычное скрытие Activity больше не выгружает её. Анимация — 200 мс; иконка — `graphics/icon/icon-3.png`.

Скачивания выполняются последовательно через WorkManager с foreground-уведомлением. Очередь и прогресс сохраняются; частичные файлы докачиваются через проверенный HTTP Range, установка публикуется только после проверки SHA-256. Android может отложить работу при Doze или исчерпании системной квоты; накопленные байты сохраняются. В мастере после запуска скачивания доступна кнопка «Далее» для настройки разрешений. Первая выбранная модель активируется после установки, другие добавляются в очередь; ручной выбор отменяет прежний автоматический.
