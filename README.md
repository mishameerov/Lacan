# Lacan

**Локальная голосовая диктовка для Android.**

Lacan превращает речь в текст и вставляет его в активное поле ввода. Плавающая кнопка работает поверх приложений, позволяя пользоваться привычной клавиатурой. Во время диктовки в панели появляется предварительный текст, а готовые расшифровки сохраняются в истории.

Распознавание выполняется на телефоне: голос и текст не отправляются на серверы. Модель можно выбрать и скачать в приложении. Есть поддержка русского и английского языков, светлая и тёмная темы, выбор цвета кнопки и отключаемый фильтр звуков заминки.

Lacan — бесплатное приложение с открытым исходным кодом.
